# 🚀 CodeFlow – Interactive DSA Visualizer

**See the logic. Trace every step. Master Data Structures and Algorithms.**

CodeFlow is an interactive Data Structures and Algorithms (DSA) visualizer designed to make learning algorithms easier and more engaging. It allows users to visualize how algorithms work through step-by-step animations, track their progress, and practice solving coding challenges.

Built with **React, TypeScript, Vite, and FastAPI**, CodeFlow combines an interactive frontend with a Python-powered backend.

---

## ✨ Features

### 🔄 Sorting Algorithm Visualizer
Visualize popular sorting algorithms with step-by-step execution:

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

Features include custom input arrays, playback controls, adjustable animation speed, and algorithm execution traces.

### 🔗 Linked List Visualizer
Explore linked list operations interactively:

- Insert at Head and Tail
- Delete by Value
- Search Elements
- Reverse Linked List
- Remove Duplicates from Sorted List (LeetCode 83)

### 📚 Stack and Queue
Understand fundamental linear data structures through interactive operations:

- Stack: Push, Pop, and Peek
- Queue: Enqueue and Dequeue
- Empty and Full Condition Handling

### 🔍 Binary Search Visualizer
Understand binary search through visual pointers:

- Left Pointer
- Middle Pointer
- Right Pointer
- Step-by-step search execution

### 🧠 Challenge Mode
Test your understanding with built-in DSA questions and interactive answer checking.

### 📊 Learning Progress
- Save learning progress using browser localStorage.
- Bookmark important algorithms and concepts.
- Export and import progress as JSON.
- Track your learning activity.

### 🎨 User Interface
- Responsive dark-themed interface.
- Interactive algorithm visualizations.
- Keyboard-friendly controls.
- Adjustable playback speed.
- Reset and custom array functionality.
